KEEPERHUB - ESTRUTURA DO PROJETO
================================

keeperhub/
|
|-- main/
|   |-- index.html
|   |   Entrada principal do HUB.
|   |-- assets/
|   |-- components/
|   |-- css/
|   |-- js/
|       Recursos especificos da tela principal.
|
|-- manifest.json
|   Arquivo reservado para a configuracao do PWA. A configuracao atual
|   ainda deve ser preenchida antes de tratar o projeto como PWA completo.
|
|-- service-worker.js
|   Arquivo reservado para o service worker. Cache offline e sincronizacao
|   devem ser documentados aqui quando forem implementados.
|
|-- package.json
|   Dependencias do projeto. Atualmente declara o Express.
|
|-- shared/
|   Recursos compartilhados por todos os modulos. Um modulo nao deve
|   importar arquivos diretamente de outro modulo.
|   |
|   |-- components/
|   |   |-- header-page.html
|   |   |   Cabecalho com titulo, retorno e controle de tema.
|   |   |-- navbar-section.html
|   |       Navegacao horizontal entre modulos.
|   |
|   |-- img/
|   |   Imagens e icones compartilhados.
|   |
|   |-- services/
|   |   |-- auth.js
|   |   |-- db.js
|   |   |-- notifications.js
|   |   |-- theme.js
|   |   |-- user.js
|   |       Servicos compartilhados. Consulte a implementacao antes de
|   |       assumir que um servico esta completamente funcional.
|   |
|   |-- styles/
|       |-- variables.css
|       |   Variaveis globais de tema e cores dos modulos.
|       |-- reset.css
|       |-- components.css
|       |-- header-page.css
|       |-- navbar-modules.css
|           Estilos compartilhados da interface.
|   |
|   |-- utils/
|       Utilitarios comuns, quando houver necessidade compartilhada real.
|
|-- modules/
|   Modulos independentes do HUB. Cada modulo possui index.html e pode
|   ter components/, assets/ e js/ proprios.
|   |
|   |-- despensa/       Controle de estoque e comparacao de precos.
|   |-- financas/       Controle financeiro.
|   |-- medicamentos/   Medicamentos, rotina, estoque e habitos.
|   |-- metas/          Gerenciamento de metas.
|   |-- pets/           Rotina e cuidados com pets.
|
|-- docs/
|   Documentacao de estrutura, padroes, recursos compartilhados e Git.

REGRAS DE DEPENDENCIA
---------------------
- Modulos podem usar recursos de shared/.
- Um modulo nao deve importar recursos de outro modulo.
- Recursos usados por mais de um modulo devem ser avaliados para shared/.
- Caminhos absolutos iniciados em / dependem de um servidor local na raiz.
