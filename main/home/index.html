Perguntas frequentes

O que é o KeeperHub?

O KeeperHub é uma plataforma de organização pessoal que reúne diferentes áreas da rotina em um só lugar.

Quais módulos fazem parte do KeeperHub?

Você pode organizar Finanças, Metas, Despensa, Pets e Medicamentos de forma integrada.

Preciso usar todos os módulos?

Não. Você escolhe os módulos que fazem sentido para o seu dia a dia.

Posso acessar pelo celular?

Sim. O KeeperHub foi pensado para acompanhar você no celular, tablet ou computador.
